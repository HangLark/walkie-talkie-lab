# Generic narrowband FM software link

This is a real FM modulation/channel/demodulation calculation in software, not an RF transmitter, radio-hardware emulator, Motorola product model, P25 codec, or claim of perceptual equivalence. No radio hardware or network transmission is used. The analog receiver now uses this model; the operator sidetone and experimental digital branch remain separate. Historical analog audio effects are described in `CUE_SIGNAL_MODEL.md` but are not layered onto this link.

## Grounding and assumptions

The official [Motorola MTR3000 specification sheet](https://www.motorolasolutions.com/content/dam/msi/docs/business/products/two-way_radios_-_public_safety/base_stations/mtr3000/documents/staticfiles/r3-2-2010a_mtr3000_spec_sht_final.pdf) specifies ±2.5 kHz deviation at 12.5 kHz channel spacing, 300–3000 Hz transmitter audio response against a 6 dB/octave emphasis characteristic referenced to 1 kHz, and a 750 µs de-emphasis condition for FM hum/noise measurement. Those are generic parameter anchors only. This implementation's Butterworth response, matched-z emphasis, filter widths, squelch timings, soft limiter and receiver audio gain are design choices, not a measured MTR3000 response. In particular its two 3 kHz low-pass stages together give roughly −6 dB at 3 kHz: that is not the specification sheet's response tolerance.

Primary technical mechanism references: [GNU Radio quadrature demodulation explanation](https://pubs.gnuradio.org/index.php/grcon/article/download/15/13/82) and [GNU Radio standard squelch implementation](https://github.com/gnuradio/gnuradio/blob/main/gr-analog/python/analog/standard_squelch.py). This module implements its own coefficients and noise detector rather than copying fixed-rate squelch coefficients.

## Signal path and units

1. Normalized mono audio enters at the host sample rate (8–192 kHz). Source leveling is an optional UI aid and defaults to zero. There is no automatic makeup gain, compressor, bit-depth reduction, pitch change, or artistic fading in the FM branch. Unity input peak at a 1 kHz test tone corresponds approximately to full rated deviation after band filtering.
2. Internal complex sample rate is `hostRate * ceil(48000 / hostRate)`, so it is always at least 48 kHz, even with an 8 kHz audio source. Low host rates use a precomputed 32-tap Blackman-windowed sinc polyphase interpolator. No arrays are allocated per sample. A matching FIR anti-alias output stage is used only when decimating. Its cutoff is 0.43 times host sample rate, avoiding accidental speech-band attenuation at 44.1 kHz.
3. A second-order 300 Hz high-pass and fourth-order 3 kHz low-pass bandlimit transmitter speech. The emphasis pole is `a = exp(-1 / (internalRate * 750µs))`. Emphasis is `(x[n] - a*x[n-1]) / ((1-a)*N)` where `N` normalizes the discrete response to unity at 1 kHz. The receiver uses the exact inverse one-pole recurrence.
4. Emphasized audio is limited to ±1; instantaneous deviation is `2500 * limitedAudio` Hz. Phase advances by `2π * deviationHz / internalRate`. Complex carrier is `cos(phase) + j*sin(phase)`, amplitude 1, power 1. There is no post-limiter speech filter; overload harmonics can enter the detector. This is an acknowledged transmitter simplification.
5. Independent seeded Gaussian I/Q noise is added **before** the receiver filter. A fourth-order Butterworth low-pass at 6 kHz processes I and Q separately. This is a simplified receive channel filter, not a recovered manufacturer's IF filter.
6. The discriminator is `atan2(imag(z[n]*conj(z[n-1])), real(z[n]*conj(z[n-1]))) * internalRate/(2π)` in Hz. The result is divided by 2500 and de-emphasized, then passed through a fourth-order 3 kHz output filter. When both the carrier and noise are absent, phase has no physical meaning: the discriminator explicitly returns zero instead of interpreting tiny filter ring-down sign changes as an FM pulse.
7. Optional speaker/resonance/body EQ follows the receiver and defaults to an uncolored line output. A final safety knee is identity below magnitude 0.85 and smoothly approaches 0.96 above it. It protects against unsquelched noise; it is not a calibrated radio amplifier. Output gain and dry/wet comparison follow. The legacy final tanh/compression stage is bypassed for analog FM.

## C/N definition and quality control

`cnrDb` is carrier power divided by **total complex noise power integrated through this exact receive filter**, in dB. It is not RSSI, dBm, distance, sensitivity, or SINAD. The constructor measures the receive filter's discrete impulse-response energy `E = sum(h[n]^2)`. Complex noise equivalent bandwidth is `internalRate * E` Hz; each input Gaussian component has standard deviation `sqrt(10^(-cnrDb/10)/(2*E))`. Thus a unit carrier and 20 dB C/N produce mean integrated I²+Q² noise power 0.01 with the carrier absent. The finite numeric range is −60 to +120 dB; Infinity means no noise generation.

The UI mapping is deliberately uncalibrated: `C/N = −8 + 0.48*quality` dB, with quality ≥99.999 giving a mathematical noiseless endpoint. Analog C/N is static at fixed control settings; the old correlated artistic quality flutter is not applied. The old `noise` slider does not affect the FM branch. Identical input, rate, seed and control timeline produce identical audio independent of block partition. Different sample rates generate different noise realizations, not sample-exact resamplings of one realization.

## Carrier, squelch and timing

PTT/VOX creates or removes the modeled carrier; speech pauses do not remove it. The host's 24 ms voice buffer remains, with 20 ms extra filter-drain allowance before carrier removal. Source audio is not cut off at PTT release. FIR resampling adds a nominal 31.5 host-sample group delay at oversampled host rates (actual subphase emission shifts this by less than one host sample); the IIR filters add frequency-dependent delay. The 24 ms comparison alignment is therefore approximate and does not undo the filters' group delay.

Squelch observes power above 4.5 kHz in the **discriminator output**, exponentially averaged over 15 ms. Threshold is `1800*exp(-squelch/33)` Hz RMS; it opens below 80% of that threshold. Received complex power must exceed 0.01. A 16 ms acquisition interval, inside the 24 ms buffer, prevents false opening before a weak-channel detector has settled. There is 120 ms hold while carrier/speech is being delivered. At carrier removal a noisy detector gets only a 6 ms release hold; the actual tail can close earlier than the user-selected maximum `tailMs`. Tail noise comes from the same RF noise and discriminator, not a synthetic audio burst. `cueLevel` does not affect analog FM.

At `tailMs=0`, the gate fades over the final 10 ms of the filter-drain allowance and is closed before RF carrier removal. At noiseless quality, silent PTT start and end are exactly silent. Normal noisy tail output can be much louder than strong-carrier background noise, as FM carrier suppression is lost; its level has not been calibrated against a physical receiver. The host's 350 ms export drain includes the voice buffer, filter drain, maximum 200 ms tail, and gate release.

## Verification and limits

- `tests/analog-fm.test.mjs`: physical phase/deviation units, clean 1 kHz roundtrip, response consistency at 44.1/48/96/192 kHz, actual noise scaling and threshold behavior, carrier versus silence detector, finite extreme inputs/CNR/rates, seed and partition invariance, short onset/sibilant release.
- `tests/fm-integration.test.mjs`: no undefined-phase release clicks; zero-tail preclosure; bounded noisy tails; weak-channel startup; selector changes during a draining burst; early onset and late sibilant preservation; re-keying and sample/block parity. Existing cue tests now test real carrier behavior while retaining exact operator permit expectations.
- Independent checks found and fixed excess 44.1 kHz decimator rolloff, undefined noiseless carrier-off phase clicks, weak-channel false acquisition, and switching receiver algorithms during a queued release.
- Independent integrated-filter noise measurements at 20 dB C/N across 8/44.1/48/96/192 kHz were 0.00995–0.01012 versus expected 0.01. Clean 1 kHz input amplitude 0.2 gives RMS ≈0.1408. 3 kHz response is ≈−6.03 dB at 44.1 and 48 kHz. Idle audio RMS at 40/30/20 dB C/N is about 0.00195/0.00617/0.0195, with nonlinear FM threshold breakdown near 0 dB.
- Actual clean CMU ARCTIC SLT/BDL human fixtures were run at 16 kHz unity input through the standalone noiseless model: output peaks 0.815/0.766 and RMS 0.0836/0.0665. SLT reached the deviation limiter on 2 of 165041 observed host samples; BDL on 0 of 159603. These are numerical checks, not listening or hardware-fidelity evidence.
- `node scripts/benchmark-fm.mjs` measures Node throughput, not browser realtime reliability. One cloud run measured 10–34 ms per audio-second at 8–192 kHz. Browser AudioWorklet performance, microphone hardware coloration and actual radio equivalence require separate verification.

Not modeled: measured microphone/speaker impulse responses, RF front-end nonlinearities, adjacent/co-channel interferers or capture effect, multipath, Doppler, calibrated fading, PLL/AFC, actual manufacturer limiter or squelch circuits, CTCSS/DCS, or any digital voice codec. No claim of perceptual realism follows from passing these tests. A same-utterance physical-radio reference and controlled listening evaluation are still needed for that claim.
